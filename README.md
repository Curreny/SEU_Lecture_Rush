# SEU_Lecture_Rush

东南大学人文与科学素养系列讲座自动预约脚本。配置账号、目标讲座和开放时间后，即可自动完成登录、验证码识别和定时预约。

## 功能特点

- **无需浏览器**：基于 Requests 运行，无需配置 Chrome 或浏览器驱动。
- **自动登录**：完成统一身份认证和 VPN 认证，遇到短信验证时按提示输入验证码即可。
- **记住设备**：首次短信验证后保存设备身份和认证 Cookie，下次启动尝试免二次验证。
- **自动识别验证码**：使用 OCR 识别图形验证码，减少手动操作。
- **到点提交**：提前检查预约资格、准备验证码，在设定的开放时间提交预约。
- **失败重试**：预约未成功时自动重新检查资格、识别验证码并尝试提交，成功后退出。
- **实时反馈**：终端显示运行进度、请求耗时和预约结果，方便了解当前状态。

## 快速开始

### 1. 安装依赖

准备 Python 3.12+ 和 [uv](https://docs.astral.sh/uv/)，在项目根目录运行：

```bash
uv sync --locked
```

### 2. 配置账号和讲座

复制配置模板：

```bash
cp .env.example .env
```

编辑 `.env`，填写账号密码和目标讲座的 `WID`：

```dotenv
WID=目标讲座的WID
username=你的一卡通号
password='你的统一身份认证密码'
```

目前每次运行支持预约一场讲座，`WID` 填写一个值。获取方式：在讲座预约页面打开浏览器开发者工具的 **Network** 面板，找到 `appiontCheck.do` 请求，查看其中的 `wid` 参数。

### 3. 设置预约时间

修改 `main.py` 顶部的时间配置：

```python
# 替换为目标讲座实际开放预约的时间：年、月、日、时、分、秒
start_time = datetime(2026, 10, 31, 19, 0, 0)

# 提前准备时间，单位为秒，默认提前 10 秒
PREPARE_SECONDS = 10
```

### 4. 运行

```bash
uv run --locked python main.py
```

建议在开放预约前提前启动，为登录和短信验证留出时间。脚本会自动等待设定时间、提交预约，成功后退出；需要停止时按 `Ctrl+C`。

## 使用说明

- 请确保网络能够访问学校认证、VPN 和讲座系统。
- 预约时间以本机时间为准，请提前校准系统时间和时区。
- 首次运行或设备信任失效时需要输入短信验证码。设备信息保存在 `.auth_state/`（已加入 Git 忽略），请勿分享；删除该目录可重置本机身份。
- 自动重试针对预约未成功的业务结果；遇到网络或程序异常时会停止，可根据终端提示排查后重新运行。
